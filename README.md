# SkillBound (friends test builds)

This repository only hosts **builds** of SkillBound for testing. The game itself is private.

## Install on Android

1. On your phone, open:
   https://github.com/Ahmed-Achtatar/skillbound-releases/releases/download/install/SkillBound.apk
2. Open the downloaded `SkillBound.apk` and allow installing from your browser when asked.
3. Tap **Install** (if Play Protect warns about an unknown app, choose *Install anyway*).

That's it: the game updates itself when you open it.
